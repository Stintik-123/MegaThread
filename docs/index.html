Статьи

Статьи пишут читатели. Пиши в редакторе, а попадает статья на сайт через Pull Request — так работает open source.

Статей пока нетБудь первым: пиши в markdown, смотри превью, черновик хранится у тебя.

Здесь появится превью…

Синтаксис: # заголовок, **жирный**, *курсив*, [текст](ссылка), - список.

Как попасть на сайт: создай в репозитории файл статьи или приложи текст к Issue — мейнтейнеры опубликуют. Черновик хранится у тебя.
