# MegaThread — каталог бесплатных ресурсов

Сайт проекта [MegaThread](https://github.com/Stintik-123/MegaThread): одностраничник на чистом HTML/CSS/JS, без сборки и без зависимостей в рантайме.
Версия 3.1 — переработана по дизайн-скиллу **Hallmark** и пересобрана по модулям, с автотестами в реальном браузере.

## Что умеет

| Возможность | Детали |
|---|---|
| Поиск | мгновенный, по названию, описанию, меткам и категориям; понимает русские синонимы («впн» → VPN, «торренты» → torrent); подсветка совпадений, ↑↓ и Enter |
| Фильтры | метки и платформы, со счётчиками; состояние фильтров пишется в URL — ссылкой можно поделиться |
| Карточка ресурса | открывается по клику на название, живёт по адресу `#/res/<название>`, показывает метки, платформы, копирование ссылки |
| Избранное | localStorage, счётчик в шапке, скачивание списком, копирование, очистка |
| Недавние | последние 12 открытых ресурсов, очищаются одной кнопкой |
| Сортировка | как в каталоге, по названию, по категории — запоминается |
| Каталог | выдаётся порциями по 48 карточек: страница не тяжелеет на 186 DOM-узлов сразу |
| Экспорт | весь каталог или избранное — в Markdown-файл |
| Установка | кнопка установки PWA появляется, когда браузер готов предложить приложение |
| Клавиатура | `/` или `⌘/Ctrl+K` — поиск, `?` — подсказка, `R` — случайный ресурс, `Esc` — закрыть |
| Темы | тёмная и светлая, выбор запоминается, по умолчанию — как в системе |
| Офлайн | service worker: навигация network-first, статика cache-first, весь каталог в кэше |
| Без JavaScript | `noscript.html` — полный каталог обычной страницей, генерируется скриптом |

## Структура

```
site/
├── index.html            # разметка: hero, поиск, факты, разделы, диалоги
├── noscript.html         # статический каталог (генерируется)
├── css/
│   ├── tokens.css        # палитра, типографика, шаг, радиусы, движение
│   ├── base.css          # floor: reset, фокус, overflow-x: clip, reduced motion
│   └── style.css         # страница: штамп, сетки, компоненты, адаптив
├── js/
│   ├── app.js            # точка входа: события, экраны, инициализация
│   ├── store.js          # состояние, localStorage, подписки
│   ├── router.js         # хэш-роутинг и deep-links
│   ├── search.js         # корпус, нормализация, синонимы, ранжирование
│   ├── catalog.js        # фильтрация, сортировка, подсчёты
│   ├── render.js         # чистые функции разметки
│   ├── icons.js          # 12 линейных глифов
│   ├── labels.js         # подписи, синонимы, подсказки клавиш
│   └── data.js           # каталог из репозитория: 12 категорий, 186 ресурсов
├── scripts/
│   └── generate-fallback.mjs   # пересобирает noscript.html после правок каталога
├── tests/
│   └── smoke.mjs         # 24 проверки в headless Chromium
├── sw.js                 # офлайн-кэш
├── manifest.json         # PWA-манифест
└── icons/                # SVG-иконки и OG-обложка
```

## Запуск

```bash
cd site
python3 -m http.server 8080   # http://localhost:8080
```

Сайту нужен `http://`, а не `file://`: модули ES и service worker не работают с локального файла.

## Тесты

```bash
node tests/smoke.mjs
```

Скрипт сам поднимает статический сервер, открывает сайт в Chromium и проверяет поведение: счётчики, поиск с синонимами, маршруты, deep-links, избранное между перезагрузками, карточку ресурса, постепенную выдачу каталога, сортировку, горячие клавиши, недавние, мобильную навигацию, сохранение темы и сортировки, статическую версию без JS и чистую консоль.

Нужен playwright: `npm i -D playwright && npx playwright install chromium`.

## Каталог

Данные лежат в `js/data.js`:

```js
export const CATEGORIES = [{ id, title, desc, icon }, ...];
export const RESOURCES  = [{ cat, name, desc, url, tags: [...], os: [...] }, ...];
```

Добавить ресурс — дописать объект в `RESOURCES`: счётчики, фильтры, поиск и номера обновятся сами.
Подписи меток и платформ (`os`: `w`, `m`, `l`, `a`, `i`, `any`) — в `TAG_LABELS` и `OS_LABELS` в `js/labels.js`.
После правки каталога пересоберите статическую версию: `node scripts/generate-fallback.mjs`.

## Hallmark-прогон

Скилл Hallmark v2.0.0 приложен без папок `references/` и `scripts/`, поэтому `theme.mjs` и `sloplint.mjs` запустить было нечем: Floor и гейты применялись вручную и проверялись в браузере.
Все цвета и шрифты живут только в `css/tokens.css`; вне токенов нет ни одного литерала.

Что изменилось против версии 3.0:

| Было | Стало |
|---|---|
| один файл `app.js` на 588 строк | восемь модулей с одной ответственностью |
| поиск по трём полям | корпус из шести полей плюс словарь синонимов |
| фильтры жили только в памяти | фильтры и карточка ресурса пишутся в URL |
| каталог рендерился целиком | 48 карточек за раз, остальное по кнопке |
| тема сохранялась неверно | исправлено, закрыто тестом |
| нет автотестов | 24 проверки в реальном Chromium |
| без JS — пустая страница | полный каталог в `noscript.html` |
