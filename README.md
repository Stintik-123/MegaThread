# MegaThread — каталог бесплатных ресурсов

Открытый каталог бесплатных ресурсов, собранный под русскоязычную аудиторию. **237 ресурсов в 13 категориях.**

У каждого ресурса есть честная метка доступности из России: работает, работает с оговорками, заблокирован или требует зеркала. Каталог не делает вид, что заблокированный сервис откроется.

Одностраничник на чистом HTML/CSS/JS: без сборки, без фреймворков, без внешних зависимостей в рантайме. Работает офлайн, ставится как PWA, читается без JavaScript.

## Что умеет

| Возможность | Детали |
|---|---|
| Поиск | мгновенный, по названию, описанию, меткам, категориям и домену; понимает русские синонимы («впн» → VPN, «торренты» → torrent, «репаки» → игры); подсветка совпадений, ↑↓ и Enter |
| Фильтры | 48 меток и 5 платформ со счётчиками; состояние фильтров пишется в URL — ссылкой можно поделиться |
| Статусы РФ | четыре состояния доступности: работает / с оговорками / заблокирован / нужно зеркало; у части ресурсов есть заметка с подробностями |
| Мини-окно | ресурс открывается отдельным окном: скриншот сайта, описание, статус доступности, метки и похожие ресурсы |
| Подборки | восемь готовых наборов: без VPN, обход блокировок, бесплатно и легально, на русском, кино, ИИ, приложения, торренты |
| Страницы | каталог, категории, подборки, облако меток, поиск, избранное, о проекте, правила — плюс статичная версия без JS |
| Карточка ресурса | открывается по клику на название, живёт по адресу `#/res/<название>`, показывает метки, платформы, копирование ссылки |
| Избранное | localStorage, счётчик в шапке, скачивание списком, копирование, очистка |
| Недавние | последние 12 открытых ресурсов, очищаются одной кнопкой |
| Сортировка | по категории, по названию, по разделу — запоминается |
| Каталог | выдаётся порциями по 48 карточек: страница не тяжелее сразу |
| Экспорт | весь каталог или избранное — в Markdown-файл |
| Установка | кнопка установки PWA появляется, когда браузер готов предложить приложение |
| Клавиатура | `/` или `⌘/Ctrl+K` — поиск, `?` — подсказка, `R` — случайный ресурс, `Esc` — закрыть |
| Темы | светлая и тёмная, по умолчанию — как в системе, выбор запоминается |
| Офлайн | service worker: навигация network-first, статика cache-first, скриншоты сайтов — отдельный кэш |
| Без JavaScript | `noscript.html` — полный каталог обычной страницей со статусами доступности, генерируется скриптом |

## Дизайн

Строгая утилитарная вёрстка: белый фон, чёрный текст, один синий акцент, прямые углы, тонкие линии, системный шрифт. Никаких градиентов, стекла, зерна, эмодзи-иконок и внешних веб-шрифтов — только содержимое и плотные строки.

Тёмная тема — холодная сине-серая: мягче чёрного, приглушённый акцент, чтобы длинные списки не резали глаза.

Все цвета, отступы, радиусы и размеры шрифтов живут исключительно в `css/tokens.css`. Вне токенов нет ни одного литерала цвета.

## Запуск

```bash
npm start            # http://localhost:8080
```

Сайту нужен `http://`, а не `file://`: модули ES и service worker не работают с локального файла. Подойдёт и любой другой статический сервер — например, `python -m http.server`.

## Тесты

```bash
npm test
```

Скрипт сам поднимает статический сервер, открывает сайт в Chromium и проверяет поведение: счётчики, поиск с синонимами, маршруты, deep-links, избранное между перезагрузками, карточку ресурса, постепенную выдачу каталога, сортировку, фильтры по меткам и платформам, горячие клавиши, недавние, статусы доступности, подборки, облако меток, страницы «О проекте» и «Правила», открытие мини-окна, мобильную навигацию, сохранение темы и сортировки, статическую версию без JS, доступность манифеста и иконок, отсутствие битых ссылок, чистую консоль и отсутствие горизонтального скролла на мобильном.

Нужен playwright: `npm i -D playwright && npx playwright install chromium`.

## Каталог

Данные лежат в `js/data.js` — это единственный источник правды:

```js
export const CATEGORIES = [{ id, title, desc, icon }, ...];
export const RESOURCES  = [{ cat, name, desc, url, tags: [...], os: [...], ru, note }, ...];
```

Добавить ресурс — дописать объект в `RESOURCES`: счётчики, фильтры, поиск и номера обновятся сами.

Поля `ru` и `note` отвечают за доступность из России:

| `ru` | Значение |
|---|---|
| `ok` | открывается из России без дополнительных инструментов |
| `limited` | работает не всегда, нужна оплата из-за рубежа или обходные ссылки |
| `blocked` | домен заблокирован РКН |
| `mirror` | нужен зеркальный домен |

Подписи меток и платформ (`os`: `w`, `m`, `l`, `a`, `i`, `any`) — в `TAG_LABELS` и `OS_LABELS` в `js/labels.js`. Синонимы для поиска — в `SYNONYMS` там же.

После правки каталога пересоберите статическую версию:

```bash
npm run build        # пересобирает noscript.html
```

## Скриншоты сайтов

Превью для мини-окна снимаются автоматически:

```bash
node scripts/fetch-previews.mjs
```

Скрипт обходит все уникальные домены каталога, снимает экран 1280×800 и складывает JPEG 640×400 (~16 КБ) в `previews/`. Сайты, которые не открылись, заменяются заглушкой с доменом. Файлы кэшируются сервис-воркером отдельно от основной статики и грузятся только при открытии мини-окна.

## Релиз

Пакет готов к публикации: это статические файлы, достаточно залить корень на любой хостинг (GitHub Pages, Netlify, Cloudflare Pages, nginx).

Перед публикацией:

```bash
npm run build        # noscript.html в актуальном состоянии
npm run build:og     # OG-обложка (нужен playwright)
npm test             # 64 проверки в реальном Chromium
```

Сервис-воркер кэширует статику по списку из `sw.js` — после релиза подними версию кэша (`CACHE = 'megathread-v8'`), чтобы клиенты получили свежие файлы.

## Лицензия и содержимое

Только легальный и бесплатный контент. Каталог открыт для всех — его можно дополнять: ссылка на «Предложить ресурс» ведёт в issues репозитория. Ответственность за то, что вы скачиваете и как используете, лежит на вас: в России распространение пиратского контента может преследоваться по закону.
