# MegaThread

Русскоязычный каталог бесплатных ресурсов интернета.  
Аналог [FMHY](https://fmhy.net/) с фокусом на РФ/СНГ.

**Сайт:** https://stintik-123.github.io/MegaThread/

## Что внутри

- 10 категорий: стриминг, игры, софт, приватность, ИИ, чтение, музыка, mobile, торренты, обучение
- 180+ ресурсов
- Быстрый клиентский поиск
- Фильтры (легальные / open source / RU)
- Статический сайт — без сервера, без аккаунтов, без аналитики

## Стек

- Vite
- Чистый JS (ES-модули)
- CSS без фреймворков

## Запуск

```bash
npm install
npm run dev
```

Сборка:

```bash
npm run build
```

## Добавить ресурс

1. Создай [Issue](https://github.com/Stintik-123/MegaThread/issues/new) с названием, ссылкой и категорией  
**или**
2. Отредактируй `src/data/resources.js` и открой Pull Request

## Важно

Сайт не хранит файлы — только ссылки.  
Использование ресурсов регулируется законами твоей страны. Мы не поощряем нарушение авторских прав.
