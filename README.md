# MegaThread

**Русский аналог [FMHY](https://fmhy.net/)** — крупнейшая коллекция бесплатных ресурсов интернета.

## Что это?

MegaThread собирает проверенные бесплатные ресурсы: стриминг, игры, софт, AI, приватность, книги и многое другое. 
Заточен под русскоязычную аудиторию (РФ/СНГ) и имеет свои уникальные фичи.

## Статус

🚧 **Макет / шаблон** — сейчас это демо-версия дизайна и структуры.

- Дизайн вдохновлён [giftovik.com](https://giftovik.com/)
- Современный тёмный UI, glass-карточки, чистая типографика
- Категории, поиск (заглушка), статистика, блок преимуществ

## Запуск локально

Просто открой `index.html` в браузере — никаких зависимостей.

Или через GitHub Pages (когда включишь):
`https://stintik-123.github.io/MegaThread/`
